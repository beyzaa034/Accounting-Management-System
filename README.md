📊 Accounting Management System (Java Swing & MySQL)

This project is a comprehensive accounting management system developed to digitalize business financial processes, ensure secure data management, and present data through visual analytics.



🚀 Key Technical Features

Object-Oriented Architecture (OOP): Built entirely on Java OOP principles (Inheritance, Polymorphism, Encapsulation) for a sustainable and modular structure.

Role-Based Access Control (RBAC): Features an authorization layer in the login system, providing different access levels for Administrators and Personnel.

Data Visualization: Financial data and budget analyses are transformed into dynamic charts using the JFreeChart library.

Database Management: Data is securely stored in a relational database designed on MySQL Workbench, utilizing JDBC connection.

🛠 Technologies Used

Language: Java

Interface: Java Swing (GUI)

Database: MySQL & JDBC

Libraries: JFreeChart (for graphical analysis)

IDE: NetBeans

📁 Project Structure

src/: All Java source codes and class structures.

images/: Icons and visual assets used in the interface.

📌 Installation

Clone this repository.

Create the MySQL database and update the settings in the db_connection file.

Run the project using NetBeans or any Java IDE.
